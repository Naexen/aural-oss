# 真人面试助手

登录 Aural 后，在左侧打开「面试助手」。录入 JD、简历文本和计划时长即可生成简报。确认考察提纲后进入「面中辅助」，选择当前主问题和说话人，再录入转写。点击「评本题」可查看暂评分、候选人原话、建议追问和下一主问题。完成后可复制面评草稿到 Moka，由面试官复核提交。

## 模型配置

把现有 DashScope 文本 API 密钥保存到部署环境中的 `HUMAN_INTERVIEW_QWEN_API_KEY`。默认模型为 `qwen-plus`，默认端点为阿里云中国内地的 `/compatible-mode/v1`。可用 `HUMAN_INTERVIEW_QWEN_MODEL` 和 `HUMAN_INTERVIEW_QWEN_BASE_URL` 指定支持 JSON 模式的模型和所在区域。配置在服务端生效。

简报请求会将 JD 和简历文本发给配置的服务。逐题评价请求只提交当前题、剩余题目和已确认的候选人片段。面试资料和评价在当前页面内保存，刷新后清空。建议仅录入获准处理的资料。

## 离线回放

「加载示例」使用虚构资料和预置评价，无需模型密钥。进入面中辅助后，逐段回放，再点击「评本题」。当前版本支持手工录入已区分说话人的转写，会议采音、自动识别说话人和 Moka API 同步仍待接入。
