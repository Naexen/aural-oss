# Aural Interview 0.1.2

Windows x64 桌面版。双击 `Aural-Interview-0.1.2-win-x64.exe` 即可独立使用。

## 使用

1. 主界面点击「开始面试」即可进入工作台。需要个性化提纲时，展开「面试资料」，粘贴 JD 和简历，并点击「生成简报」。
2. 当面面试可打开「电脑麦克风」，也可在面中点击「开启麦克风」。启用已配置的语音服务后，工作台会显示转写。麦克风也可用于本地音量检测，发言可手动补录。
3. 使用「录入归属」指定新片段的说话人，或在每段转写上改标签。共用一支麦克风时，默认标签为「待确认」。只有归属为候选人的已定稿片段会发给评分模型。
4. 点击右上角「浮窗」，可拖到腾讯会议等应用旁边并保持置顶。浮窗提供转写、评估和常用操作，横线按钮可收起。桌面版采集默认麦克风音轨，会议软件远端音轨需另行接入。
5. 结束面试后，可整理和复制面评草稿，在 Moka 中复核、提交。

## 配置自己的接口

- **默认文本模型**在「模型设置」里选择 OpenAI Compatible 或 Anthropic Compatible，填写 API 地址和 API Key，点击「读取模型」。选中服务返回的模型后点击「保存并测试」。兼容网关需提供模型列表接口，通常为 `GET /v1/models`。远程 API 地址使用 HTTPS，本机网关可使用回环 HTTP。
- **语音识别**支持阿里云千问和火山引擎豆包实时转写，通常只需填写相应服务的 API Key。接口版本、资源 ID 和自定义地址在「高级设置」里。
- **兼容转写服务 · Whisper**支持提供 `POST /v1/audio/transcriptions` 的服务，例如自建的 faster-whisper 兼容服务。软件把麦克风音频切成短 WAV 片段，收到响应后显示定稿。请填写服务地址，本机回环服务可以留空 API Key。「高级设置」里的模型名按服务实际提供的 ID 设置。
- **面前简报、文字整理、提问、评分**默认共用文本模型。可以关闭对应任务的「使用默认文本模型」，填入独立的 API 配置。

旧版保存的文本与语音设置可以继续使用。Windows 使用系统加密保存 API Key。「读取模型」使用当前表单连接信息，点击保存后才更新本机设置。面试资料、转写和评价保存在当场会话内。启用相应功能时，音频、简历或转写会按任务发送到你指定的服务。

## 从源码运行

在仓库的 `desktop` 目录运行 `npm ci` 和 `npm start`。使用 `npm run package:win` 构建 Windows x64 便携版，输出在 `desktop/build/package`。
