# Aural Interview 0.1.0

Windows x64 桌面版。打开便携版 `Aural-Interview-0.1.0-win-x64.exe` 即可使用。独立运行无需 Aural 网站、数据库或登录。

## 使用

1. 主界面点击「开始面试」即可进入工作台。需要个性化提纲时，展开「面试资料」，粘贴 JD 和简历，并点击「生成简报」。
2. 当面面试可拨开「电脑麦克风」，也可在面中点击「开启麦克风」。配置并启用在线语音识别后，软件会实时转写。没有 ASR 配置时，麦克风可用于本地音量检测，也可以手动补录发言。
3. 使用「录入归属」指定新片段的说话人，或在每段转写上改标签。共用一支麦克风时，默认标签为「待确认」。只有归属为候选人的已定稿片段会发给评分模型。
4. 点击右上角「浮窗」，可拖到腾讯会议等应用旁边并保持置顶。浮窗提供转写、评估和常用操作，横线按钮可收起。桌面版采集默认麦克风音轨，会议软件远端音轨需另行接入。
5. 结束面试后，可整理和复制面评草稿，在 Moka 中复核、提交。

## 配置自己的接口

- **默认文本模型**支持 OpenAI 兼容接口和 Gemini 原生接口。填写 API 地址、模型 ID 和 API Key，选择「保存并测试」。默认填入千问兼容地址和 `qwen-plus`。文本模型的远程 API 地址使用 HTTPS，本机网关可使用回环 HTTP。
- **语音识别**支持 Qwen Audio 和 Qwen Realtime。开启在线语音识别，填入对应区域的 DashScope API Key。API 地址和模型 ID 可使用内置默认值，也可按所选协议填写；自定义语音地址使用 WSS。
- **面前简报、文字整理、提问、评分**默认共用文本模型。可以关闭对应任务的「使用默认文本模型」，填入独立的 API 配置。

Windows 使用系统加密保存 API Key。面试资料、转写和评价保存在当场会话内。启用相应功能时，音频、简历或转写会按任务发送到你指定的服务。

## 从源码运行

在仓库的 `desktop` 目录运行 `npm ci` 和 `npm start`。使用 `npm run package:win` 构建 Windows x64 便携版，输出在 `desktop/build/package`。
